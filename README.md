# LabLedger 0.1.0 plugin marketplace

Generated release packages for Codex and Claude Code.

Install in Claude Code:

```text
/plugin marketplace add anhnh2002/LabLedger#marketplace
/plugin install labledger@labledger
```

Install in Codex:

```sh
codex plugin marketplace add anhnh2002/LabLedger --ref marketplace
codex plugin add labledger@labledger
```

See https://github.com/anhnh2002/LabLedger for installation instructions and source.
Contribute on the source branch; this branch is updated by the release workflow.
