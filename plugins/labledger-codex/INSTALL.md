# LabLedger 0.1.0 for codex

Install this plugin through the host's plugin controls.
Use every LabLedger workflow inside a Codex or Claude Code session. The Python
backend is bundled; no LabLedger executable or separate core installation exists.
Python 3.11+ is required on macOS/Linux. The agent's private helper prepares pinned
dependencies in a user cache on first use (package-index access is needed once).
No server or API key is required. All package resources resolve from this folder.
Use a fresh host session after installation and verify skill discovery.
This default package contains no hooks and requires no lifecycle-hook support.
